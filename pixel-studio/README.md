# 像素工坊：图片转换与 Blingee 个性化

Python 本地窗口软件，支持从电脑选择图片、调整像素颗粒、生成预览并保存 PNG。图片不会上传到服务器。

## 运行

需要 Python 3.10 或以上、Tkinter 和 Pillow。在本目录打开终端：

```powershell
python -m pip install -r requirements.txt
python app.py
```

Windows 官方 Python 安装通常包含 Tkinter。也可双击 `启动.bat`（需要已安装上述依赖）。

## 操作

1. 点击“选择图片”，选择 PNG、JPEG、WebP、BMP 或 GIF；GIF 只读取首帧。
2. 设置颗粒大小，范围 1～256；数字越大，图像越粗。1 保留原始像素。
3. 点击“生成像素图”，在右侧查看结果；修改参数后重新生成。
4. 点击“保存 PNG”，选择新文件名。软件阻止覆盖当前原图。

采用区域平均缩小、最近邻放大。输出保持原尺寸和透明通道；边缘像素块因尺寸不能整除可能略有差异。预览自动适应窗口、不放大小图；棋盘格只用于显示透明区域，不会写入导出文件。图片上限为 2000 万像素；接近上限的图片可能短暂占用界面线程。

## 第二阶段：Blingee 个性化

1. 生成像素图后，勾选“启用 Blingee”，右侧预览播放闪粉动画。
2. “闪粉特效”可独立关闭；“播放预览”可以暂停动画，不影响 GIF 导出。
3. 从下拉框选择爱心、星星或蝴蝶结，设置大小（图片短边的 5～40%），点击右侧图片放置贴纸。可以重复放置、撤销最后一张或清空，最多 100 张。
4. “保存 PNG”输出静态首帧，保持原图尺寸和透明通道；“导出 GIF”输出循环动画。

关闭 Blingee 可恢复普通像素图，贴纸布局仍然保留。重新生成像素图保留当前贴纸布局；选择新图片会清空贴纸。贴纸来自程序绘制，无外部素材下载。

为控制内存与导出时间，动态预览和 GIF 最长边限制为 720 像素，不放大小图。闪粉使用 12 帧、每帧 160 毫秒循环；关闭闪粉时导出为单帧 GIF。GIF 将透明区域转为白色，PNG 则保留透明背景。GIF 的有限调色板可能造成颜色变化。

## 文字留言

生成图片后，在“文字留言”输入框输入最多 300 字（支持中文、英文和换行），勾选“显示留言”。字体固定，Windows 使用系统微软雅黑；其他系统回退为 DejaVu Sans，其中文支持取决于字体环境。可通过“选择颜色”选择文字颜色。

勾选“调整留言区域”，在右侧图片上的青色虚线框内部拖动可移动区域，拖动右下角方块可调整宽高，区域限制在图片内部。文字自动换行并随区域大小缩小字号；过小区域或极小输出可能导致文字不清晰，建议放大区域。调整模式下不会放置贴纸；取消勾选即可继续贴纸操作。重置区域恢复默认位置。

留言独立于 Blingee 开关，保存 PNG 和 GIF 均包含留言；仅文字时 GIF 为单帧。青色虚线和缩放手柄只用于编辑，不会导出。文字与位置在重新生成和选择新图时保留，可清空输入或关闭“显示留言”。

当前不包含贴纸拖动、自由画笔、用户自定义贴纸上传或反馈收集。

## 验证

```powershell
python -m unittest discover -s tests -v
```

自动验证尺寸、透明度、平均取色、边界尺寸、非法参数、PNG 往返读写、贴纸位置、动画变化和 GIF 帧数/时长。界面完整交互仍需人工试用。
