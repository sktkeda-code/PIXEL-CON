# 像素工坊：第一阶段

Python 本地窗口软件，支持从电脑选择图片、调整像素颗粒、生成预览并保存 PNG。图片不会上传到服务器。

## 运行

需要 Python 3.10 或以上、Tkinter 和 Pillow。在本目录打开终端：

```powershell
python -m pip install -r requirements.txt
python app.py
```

Windows 官方 Python 安装通常包含 Tkinter。也可双击 `启动.bat`（需要已安装上述依赖）。

## 操作

1. 点击“选择图片”，选择 PNG、JPEG、WebP、BMP 或 GIF；GIF 只读取首帧。
2. 设置颗粒大小，范围 1～256；数字越大，图像越粗。1 保留原始像素。
3. 点击“生成像素图”，在右侧查看结果；修改参数后重新生成。
4. 点击“保存 PNG”，选择新文件名。软件阻止覆盖当前原图。

采用区域平均缩小、最近邻放大。输出保持原尺寸和透明通道；边缘像素块因尺寸不能整除可能略有差异。预览自动适应窗口、不放大小图；棋盘格只用于显示透明区域，不会写入导出文件。图片上限为 2000 万像素；接近上限的图片可能短暂占用界面线程。

当前只包含第一阶段功能，不包含画笔、贴纸、反馈收集或动画导出。

## 验证

```powershell
python -m unittest discover -s tests -v
```

自动验证尺寸、透明度、平均取色、边界尺寸、非法参数及 PNG 往返读写。界面完整交互仍需人工试用。
